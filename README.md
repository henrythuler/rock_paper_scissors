# P2P Rock Paper Scissors Smart Contract

A smart contract project for the Rock, Paper, Scissors game on the EVM blockchain.

## Description

This project implements a smart contract that allows playing Rock, Paper, Scissors in a decentralized way on the blockchain. Players can compete with each other safely and transparently.

## Prerequisites

- Node.js (v20 or higher)
- npm or yarn
- A Web3 wallet (MetaMask, etc.)

## Installation

1. Clone the repository:
```bash
git clone <your-repository>
cd rockpaperscissors
```

2. Install the dependencies:
```bash
npm install
```

## How to Run

### Compile the contract:
```bash
npm run compile
```

### Deploy to test network:
```bash
npm run deploy
```

### Run tests:
```bash
npm run test
```

### Start local server:
```bash
npm run dev
```
