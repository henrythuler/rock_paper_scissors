# P2P Rock Paper Scissors Smart Contract

A Solidity smart contract project for the Rock, Paper, Scissors game on the EVM blockchain.

## Description

This project implements a smart contract that allows playing Rock (0), Paper (1), Scissors (2) in a decentralized way on the blockchain. Players can compete with each other safely and transparently.

## Prerequisites

- Node.js (v20 or higher)
- npm or yarn
- Hardhat

## Installation

1. Clone the repository:
```bash
git clone <your-repository>
cd rockpaperscissors
```

2. Install the dependencies:
```bash
npm install
npm install hardhat
npm install dotenv
```

## How to Run

### Compile the contract:
```bash
npx hardhat compile
```

### Run tests:
```bash
npx hardhat test --network hardhat
```
